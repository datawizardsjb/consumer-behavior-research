# Consumer Behavior Research Project

## Overview
This community service research project focuses on understanding consumer behavior patterns and factors influencing purchasing decisions in local markets.

## Project Scope
- **Objective:** To identify the personal, social, and psychological factors that influence consumer buying behavior.
- **Methodology:** Conducted field research, including primary data collection through visits to local shops and interviews with young entrepreneurs, complemented by secondary research.
- **Key Findings:** The study explores how variables like age, occupation, lifestyle, and social reference groups dictate purchasing trends.
